# 🦭 Nightmare Eater · 噩夢記錄器

sirotan02的夢境手帳。HTML、CSS、原生 JavaScript；無建置依賴、無後端、無追蹤服務。海豹只負責吃。

## 本機預覽

需要 Node.js 20 或以上：

```sh
npm start
```

開啟 http://127.0.0.1:4173 。不要直接開啟 `index.html`：ES modules 與離線功能需要 HTTP／HTTPS。預覽伺服器僅供本機開發。

```sh
npm test
npm run check
```

## GitHub Pages

在 GitHub repository 的 **Settings → Pages → Source** 選 **GitHub Actions**。把網站提交到 `main`，或手動執行 Deploy to GitHub Pages workflow。若預設分支不同，調整 `.github/workflows/pages.yml` 的分支。部署只上傳網站資源，不包含測試或任何使用者資料。

所有資源使用相對路徑，可部署於 `/NightmareRecord/` 等子路徑。首次連線完成快取後可離線使用。修改網站資源時，請提升 `sw.js` 的 `CACHE` 版本；新版等待舊視窗關閉後啟用，不強制重載正在編輯的畫面。

## 記錄規則

- 夜間記錄預設昨天；午覺夢預設今天。日期以裝置本地日曆計算。
- 夜間狀態有「有／無／不記得」，未填為未記錄；睡眠時數可略過。
- 夜間夢境表單可直接填睡眠時數，與首頁共用同一晚的數值；改日期會載入該日的時數，午覺不修改夜間時數。草稿保留各日期的時數，正式餵海豹時才一併保存目前日期的時數。
- 觀察頁分五區：概覽、趨勢、夢境模式、睡眠與影響、進階分析。睡眠分析按少於 5、5–未滿 7、7–未滿 9、9 小時以上分組，列出納入與排除的晚數及每組分母；確定有／無少於 5 晚的組只列晚數，不顯示百分比。分組只是描述性比較，不推論因果。
- 夜間平均評分先按晚平均，再平均各晚；午覺／全部按夢境計算。零分有效，未填不算零；每個指標都標明單位（晚或個夢）及有評分、沒評的數量。
- 夜間噩夢率 = 有噩夢的夜晚 ÷ 確定有或沒有噩夢的夜晚。「不記得」與「未記錄」不進分母，也不當作沒有噩夢。今天的夜晚尚未結束、今天之後的日期不算未記錄，也不納入統計。樣本少於 10 晚或記錄覆蓋低於 60% 時會顯示提示（門檻是設計上的判斷，見 `core.js` 的 `ANALYSIS`）。
- 趨勢以 7 或 30 天滾動窗口計算，標明每個指標是比率、滾動計數還是平均值。窗口內有效樣本不足（比率與睡眠時數至少窗口一半的晚數、評分至少 3 晚）就不畫，也不當作 0。
- 分類標籤的百分比以有填該類標籤的晚（或夢）為分母；沒填的另行列出，不當作「沒有」。多選分類合計可超過 100%。
- 稀有度是主觀的趣味等級：只列分布、中位數和最常見等級，百分比只計已評級的夢，未評級另列；不計平均稀有度。
- 「屬於夢境系列」與「標記為重複出現（夢的結構：輪迴 / Recurring）」分開統計，單位標明為晚或個夢。
- 預設內容標籤新增迷路、遲到、考試／學業、工作／任務失敗、被監視、被拒絕／排斥、背叛、失去重要的人、自然災害、交通事故、鬼怪／靈異、無法動彈、窒息／無法呼吸、牙齒脫落；原有與自訂標籤保留。
- 每個夢有夜間／午覺分類。午覺不改變夜間狀態，也不計午覺發生率。
- 刪除或移動夜間夢細節不會自行取消原晚「有噩夢」；請另行修改夜間狀態。
- 同日期夜間與午覺共同取最高稀有度計 EXP。只有「有」狀態或未評級夢也有 10 EXP。獎勵從資料重新計算。
- 系列狀態手動設定；同一系列可有夜間及午覺 episode。

## 備份與私隱

記錄儲存於目前來源的 localStorage，未加密、不上傳、沒有帳號或同步。網站程式可以公開部署，個人資料不會寫進 repository。清除瀏覽資料、卸載或瀏覽器儲存回收可能令資料消失。

請定期在設定匯出 JSON 並另存至 iPhone「檔案」或你選擇的備份位置。Safari 與加入主畫面的 App 不假定共用儲存空間；切換前匯出，切換後匯入。

- JSON 包含版本、每日狀態、夢境、系列、自訂分類、設定和草稿。
- 合併以本機日期和夢境 ID 優先：衝突日期的整天資料不匯入；保留本機草稿及設定，合併自訂分類和新系列。
- 完整還原會取代目前資料，需要確認；匯入前保留本機回復副本。這份副本也會隨網站資料被清除，不能代替外部備份。
- CSV 分每日摘要和夢境明細，不是完整備份；若瀏覽器阻擋第二份下載，可分別下載。
- 資料損壞時停止寫入，設定可下載原始檔或以有效 JSON 還原。儲存額度不足時保留畫面輸入，不顯示成功動畫。
- 多個視窗同時修改會停止後續寫入，請先匯出目前視窗，再重新載入。

## 結構

- `core.js`：日期、資料驗證、合併、統計、趨勢和獎勵，與介面分開。
- `storage.js`：本機儲存與匯入回復副本。
- `app.js` / `styles.css`：手機介面與 emoji 海豹；日後可在呈現層更換貼圖。
- `sw.js` / `manifest.webmanifest`：離線與主畫面 App。
- `tests/core.test.js`：統計口徑、午覺隔離、資料往返、衝突與失敗情境。

## 真機驗收

桌面手機尺寸預覽不能代替 iPhone。發布後請在 Safari 與主畫面模式各檢查：三態快速保存、午覺與夜間並存、長文及鍵盤遮擋、切背景後草稿恢復、飛航模式重新開啟、JSON 存至「檔案」並還原、兩份 CSV 下載、安全區與減少動態效果。不要用私人瀏覽作長期儲存。
